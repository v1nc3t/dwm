dwm shortcuts
Super is the main modifier. Alt is only used for launching programs.

Launch
Super+Enter              terminal (qterminal)
Super+c                  application launcher (rofi)
Super+u                  select a region and copy it to the clipboard
Super+Ctrl+u             copy the whole screen to the clipboard
Super+p                  display settings (arandr), same as F7
Ctrl+Alt+Tab             swap tile and bottom stack, same as F11
Super+l                  lock the screen, same as F10
Alt+w                    Firefox
Alt+f                    Thunar
Alt+d                    Discord
Alt+c                    VS Code
Alt+m                    Spotify
Alt+b                    terminal running btop

Windows
Super+j                  focus next window
Super+k                  focus previous window
Super+Shift+Enter        move focused window to master
Super+q                  close focused window
Super+b                  show or hide the bar
Super+Shift+h            shrink master area
Super+Shift+l            grow master area
Super+i                  add a master slot
Super+d                  remove a master slot
Super+Shift+Space        float or unfloat the focused window

Layouts
Super+t                  tile
Super+f                  floating
Super+m                  monocle
Super+Space              swap between the last two layouts
F9                       swap between tile and floating
F11                      swap between tile and bottom stack (top/bottom split)

Tags
Super+1 .. Super+9       show that tag
Super+Ctrl+1 .. 9        add or remove that tag from the view
Super+Shift+1 .. 9       move the focused window to that tag
Super+Ctrl+Shift+1 .. 9  add or remove that tag on the window
Super+0                  show every tag
Super+Shift+0            put the focused window on every tag
Super+Tab                go back to the previous tag view
Super+Left               previous tag
Super+Right              next tag

Monitors
Super+,                  focus previous monitor
Super+.                  focus next monitor
Super+Shift+,            send the window to the previous monitor
Super+Shift+.            send the window to the next monitor

F row
A plain press does the printed action while Fn lock is off.
Fn + any F key sends the real F key to the focused program.
F1                       mute
F2                       volume down
F3                       volume up
F4                       mute microphone
F5                       brightness down
F6                       brightness up
F7                       display settings (arandr)
F8                       airplane mode (kernel)
F9                       swap between tile and floating
F10                      lock the screen
F11                      swap side by side and top/bottom split
F12                      calculator (mate-calc)
Print                    select a screen region and copy it to the clipboard

Bar
Click layout symbol      swap between the last two layouts
Scroll on volume         change the volume
Scroll on brightness     change the brightness
Left-click mic           mute or unmute the microphone
Left-click CPU or RAM    open btop
Left-click network       open nmtui

Quit
Super+Shift+q            quit dwm (closes every window)
